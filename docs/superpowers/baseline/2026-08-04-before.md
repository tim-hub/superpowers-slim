## Environment fixes required to run these tests at all

Two pre-existing defects blocked every headless test. Both were fixed before measuring, and
the fixes are part of this commit:

1. `--output-format stream-json` with `--print` requires `--verbose` on Claude Code 2.1.220.
   Without it the CLI exits immediately with
   `Error: When using --print, --output-format=stream-json requires --verbose`,
   and the harness reports a FAIL that looks behavioral but is not. This affected
   `tests/explicit-skill-requests/run-test.sh` as shipped upstream.
2. Both runners wrote to a hardcoded `/tmp/superpowers-tests/...`, which is not writable
   under this sandbox. Changed to `${TMPDIR:-/tmp}`.

The first FAIL recorded during this task was a false negative from defect 1. It is not
included below; the results here are from runs after both fixes.

## Correction, 2026-08-06 — a third defect went unnoticed, and it invalidates 1b

Both runners ran the agent inside the output directory, so `superpowers-tests` sat in its cwd while
the test measured whether a skill fired. Varying only the cwd name: 6/6 fired with that string
present, 0/15 with a neutral name. The PASS in section 1b is a measurement of the directory name.
Fixed in `a757bc2`. Details in `2026-08-04-after.md`.

Section 1a is contaminated differently: no runner isolates `HOME`, so personal skills in
`~/.claude/skills` shadow the plugin's. The unprefixed names in that output — `brainstorming`,
`systematic-debugging`, `subagent-driven-development` — are consistent with personal copies answering
rather than this tree.
